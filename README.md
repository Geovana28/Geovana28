### 📂 Projetos em Destaque

#### 🚌 [bh-transit-ai](https://github.com/Geovana28/bh-transit-ai)
> Solução inteligente inspirada na mobilidade urbana de Belo Horizonte (estilo Moovit), aplicando conceitos de inteligência artificial para otimização, busca e análise de rotas de transporte público.
- **Foco:** Algoritmos de busca em IA, heurísticas e processamento de trajetos urbanos.
- **Stack:** Python, Algoritmos de IA e Modelagem de Dados.

#### 📊 [edudata-analytics](https://github.com/Geovana28/edudata-analytics)
> Projeto focado na exploração e análise analítica de indicadores educacionais, permitindo identificar tendências de aprendizagem e padrões em bases de dados acadêmicas.
- **Foco:** Análise exploratória de dados (EDA), métricas e visualização de impacto.
- **Stack:** Python, Pandas, Matplotlib/Seaborn e Ciência de Dados.

#### ♻️ [TrabalhoOds](https://github.com/Geovana28/TrabalhoOds)
> Sistema em Java estruturado com base nos Objetivos de Desenvolvimento Sustentável (ODS da ONU), focado em logística, gestão de resíduos e incentivo ao descarte consciente de materiais recicláveis.
- **Foco:** Programação Orientada a Objetos (POO), regras de negócio sustentáveis e arquitetura modular.
- **Stack:** Java e Conceitos de Engenharia de Software.

#### 🦟 [dengue](https://github.com/Geovana28/dengue)
> Mapeamento epidemiológico e tratamento de dados de saúde pública para visualização e análise de casos de dengue ao longo do tempo.
- **Foco:** Pré-processamento, limpeza, agregação de indicadores e estatística.
- **Stack:** Python e Análise de Dados.
